## 📁 Course Details

### 🔹 [CSE 222 — Data Structures and Algorithms](./CSE222-Data-Structures-and-Algorithms/)
* **Language:** Java
* **Key Topics:** Abstract Data Types (ADTs), Dynamic Arrays, LinkedList, Stack, Queue, Priority Queues, Binary Trees, AVL Trees, Heaps, Hash Tables, Graph Traversals (BFS/DFS), Shortest Path (Dijkstra), Sorting Algorithms, Asymptotic Complexity.
* **Contents:**
  * `Lectures/` — Course slides and lecture notes.
  * `CSE222_Homeworks/` & `hw7-8/` — Java homework solutions and project code.
  * `Data_Structures_study_codes/` — Practice codes, algorithm implementations, data structure tests.
  * `data_final_exams/` — Past final exam questions and study notes.

### 🔹 [CSE 232 — Logic Circuits and Design](./CSE232-Logic-Circuits-and-Design/)
* **Key Topics:** Number Systems, Boolean Algebra, Canonical Forms, K-Map Minimization, Combinational Circuits, Latches & Flip-Flops, Counters, Shift Registers, Finite State Machine (FSM) Design (Mealy & Moore).
* **Contents:**
  * `slides/` — Chapter presentation slides.
  * `Logic.pdf` — Complete reference textbook & course manual.

### 🔹 [CSE 234 — Logic Design Lab](./CSE234-Logic-Lab/)
* **Key Topics:** Practical logic design, Verilog Hardware Description Language (HDL), Logisim digital circuit modeling, combinational & sequential circuit synthesis, laboratory experiments.
* **Contents:**
  * `LAB#1/` — Introductory laboratory project.
  * `cse_234_exs/` — Practice exercises and Verilog modules.
  * `logic_lab/` — Core lab assignments and simulation files.

### 🔹 [MATH 217 — Linear Algebra & Differential Equations](./MATH217-Linear-Algebra-and-Differential-Equations/)
* **Key Topics:** Matrix Operations, Determinants, Gaussian Elimination, Vector Spaces, Subspaces, Basis & Dimension, Eigenvalues & Eigenvectors, First-Order Ordinary Differential Equations (ODEs), Second-Order Linear ODEs, Laplace Transforms.
* **Contents:**
  * `MATH217_250410_203222.pdf` — Comprehensive course lecture notes & handwritten solutions.
  * `OneDrive_1_13.04.2025.zip` — Supplementary lecture slides and practice problems.

### 🔹 [PES 140 — Voluntary Work](./PES140-Voluntary-Work/)
* **Key Topics:** Social Responsibility, Team Dynamics, Project Management, Community Impact, Academic Reporting.
* **Contents:**
  * `RAPOR.docx` — Official voluntary project final report.
  * `vize sunum/` & `final sunum/` — Midterm and final presentation slides.
  * `photos/` — Photo documentation of completed social responsibility activities.
